## Real Roblox / executor tests
**NONE were run — recorded here so the gap is explicit, not implied.** The deliverable's GUI
construction (PlayerGui / CoreGui hook / ScreenGui), `RunService.Heartbeat` draining, clipboard and
filesystem writes require a real executor or Roblox Studio session, which this environment does not
have. Per the release requirements, "the application opens" is therefore NOT claimed: the artifact
prints `not constructed (console mode)` outside Roblox and `constructed (<gui parent>)` inside one —
verify the latter in your target runtime before trusting the UI.

## What these results mean — and do not mean
* The Luau suite runs in the **standalone Luau CLI against a mock environment**. **Not** in Roblox, **not** in any executor. Executor compatibility is **UNVERIFIED**.
* The deliverable smoke test runs the actual single file headless (no mocks) — proves it loads and analyzes.
* Detection counts are regression-test counts, not accuracy measurements.
* No detection accuracy benchmark has been published (a labeled corpus would be needed).
